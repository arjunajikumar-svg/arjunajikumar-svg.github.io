# Arjun Ajikumar — Data Analyst Portfolio

Personal portfolio website, hosted free with GitHub Pages.

**Live site:** https://arjunajikumar-svg.github.io/

## Folder structure
```
index.html          page structure
css/style.css       all styling
js/config.js        YOUR DETAILS: links, photo, projects (edit this)
js/main.js          animations, menu, project cards
assets/profile.webp profile photo
assets/thumbs/      project thumbnails
```

## Add a new project
Open `js/config.js`, copy a project block, change the title, description, tools and GitHub link, and upload a thumbnail to `assets/thumbs/`.
